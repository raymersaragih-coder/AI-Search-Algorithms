## 2. Introduction (Project Description)

This project demonstrates the integration of an Artificial Intelligence graph search algorithm (**Dijkstra's Search Algorithm**) with a closed-loop **Proportional-Integral-Derivative (PID) Controller** for autonomous mobile robot navigation.

In autonomous control systems, navigation is divided into two hierarchical layers:
1. **Global Path Planner (AI Search Algorithm):** Represents the environment as a discrete grid graph, searching for the shortest obstacle-free sequence of waypoints from the initial state (*Start*) to the target state (*Goal*).
2. **Local Motion Controller (PID Control System):** Receives the waypoints generated by the search algorithm as reference setpoints and computes the required angular velocity command ($\omega$) to minimize heading error ($e_\theta$) until the robot reaches the target.
