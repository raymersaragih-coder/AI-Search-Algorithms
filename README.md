# 🔍 AI Search Algorithms (BFS & A*)

Repository ini berisi implementasi algoritma pencarian untuk tugas mata kuliah **Kecerdasan Buatan (Artificial Intelligence)**.

---

## 📌 Algoritma yang Diimplementasikan
- **Breadth-First Search (BFS)**: Mencari rute berdasarkan jumlah langkah/kedalaman paling sedikit.
- **A* (A-Star) Search**: Mencari rute paling optimal berbasis fungsi heuristik $f(n) = g(n) + h(n)$ untuk meminimalkan total *cost*/jarak.

---

## 🚀 Cara Menjalankan di Laptop Masing-Masing (Local Execution)

```bash
cd aima-python-master
python main.py
```
